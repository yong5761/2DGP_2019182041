## 2. 기능 요구사항

### 2-1. 이동 (3점)
- 상하좌우 방향키(`↑ ↓ ← →`)로 캐릭터를 이동한다.
- 동시 입력(대각선)을 지원한다.
- 이동 속도: **5 px / 프레임** (20fps 기준).

### 2-2. IDLE 애니메이션 (1점)
- 방향키를 아무것도 누르지 않은 상태(dx = 0, dy = 0)에서는 IDLE 애니메이션을 재생한다.
- IDLE 행: Row 3 (clip_y = 300), 8프레임.

### 2-3. 이동 방향 애니메이션 (채점 포함)
- **오른쪽 이동**: Row 1 (clip_y = 100), 8프레임.
- **왼쪽 이동**: Row 0 (clip_y = 0), 8프레임.
- **상하 이동**: 마지막 좌우 방향(`facing`)을 유지하여 Row 0 또는 Row 1 재생.
  - 최초 기본 방향: `right`.

### 2-4. 화면 경계 (1점)
- 캐릭터가 캔버스 밖으로 나가지 않는다.
- 경계 여유(MARGIN): 스프라이트 반 크기(= 50 px).
- `x` ∈ [50, 1230], `y` ∈ [50, 974].

`animation_sheet.png` — 셀 크기 100 × 100, 열 8개, 행 4개

pico2d y │ 이미지 위치  │ 내용          │ 프레임 수 │ 사용 여부
─────────┼─────────────┼───────────────┼──────────┼──────────
  300    │ 최상단(Row3) │ IDLE          │    8     │ ✓

## 4. 상태 머신

```
             dx=0, dy=0
  ┌─────────────────────────┐
  │                         ▼
  │          ┌──────────────────────────┐
  │          │          IDLE            │
  │          │  Row3 (clip_y=300), 8f   │
  │          └──────────────────────────┘
  │                         │
  │            방향키 입력   │
  │                         ▼
  │          ┌──────────────────────────┐
  └──────────│         MOVING           │
             │  facing='right' → Row1   │
             │  facing='left'  → Row0   │
             └──────────────────────────┘
```

---

## 5. 입력 처리 설계

```
keys 딕셔너리: {SDLK_RIGHT, SDLK_LEFT, SDLK_UP, SDLK_DOWN} → bool

KEYDOWN → keys[key] = True
KEYUP   → keys[key] = False

dx = (RIGHT 눌림) - (LEFT 눌림)   # -1, 0, +1
dy = (UP 눌림)   - (DOWN 눌림)    # -1, 0, +1

facing 갱신 (update 함수 내):
  dx > 0 → facing = 'right'
  dx < 0 → facing = 'left'
  dx = 0 → facing 유지
```

---

## 6. 렌더링 파이프라인 (매 프레임)

```
1. handle_events()   — 입력 수집
2. update()          — 위치·facing·frame 갱신, 경계 클램핑
3. draw()            — clear → 배경 → 캐릭터 → update_canvas
4. delay(0.05)       — ~20 fps 유지
```
